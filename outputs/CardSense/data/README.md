# Data

The Kaggle CSV was not found in the project. Download `BankChurners.csv` from [IBM Credit Card Customers](https://www.kaggle.com/datasets/sakshigoyal7/credit-card-customers): sign in, choose Download, extract the archive, and place the original file at `data/raw/BankChurners.csv`. No data has been fabricated or substituted. Keep the raw source unchanged. Cleaning outputs a separate `data/processed/cleaned_customers.csv`.

The raw and processed CSVs are excluded from Git. Review Kaggle's license/terms before redistribution.
